# TRACAL — Product validation kit

สถานะ: ชุดทดลองพร้อมใช้ แต่ยังไม่มีผู้เข้าร่วมและไม่มีข้อมูลรายได้จริง ณ 2026-09-08

## เป้าหมาย

ทดสอบว่าผู้ใช้ไทยสามารถคำนวณผลตอบแทนสุทธิเป็นบาท เข้าใจผลของค่าเงิน บันทึกแผน และกลับมาใช้แผนเดิมได้ โดยไม่ต้องอธิบายสูตรล่วงหน้า

## กลุ่มทดลองและงานที่ให้ทำ

รับผู้ทดลอง 10–15 คนที่เคยซื้อ Crypto Spot หรือทองอ้างอิง USD ใช้รหัสเช่น `P01` แทนชื่อจริง และไม่ขอ API key, statement เต็มบัญชี หรือข้อมูลส่วนตัวที่ไม่จำเป็น

1. ใช้ตัวเลขสมมติหรือรายการของตนเองสร้างผลคำนวณหนึ่งรายการ
2. อธิบายด้วยคำของตนเองว่ากำไรใน USD และกำไรสุทธิ THB ต่างกันอย่างไร
3. เปลี่ยนเรตขายให้เกิดกรณีสินทรัพย์กำไร แต่เงินบาทขาดทุน
4. สร้างแผนขาดทุนจาก Stop และวงเงินที่รับได้
5. บันทึกแผน ปิดหน้า แล้วเปิดแผนนั้นใหม่
6. ถ้ามีประวัติหลายไม้ ให้ทดลองสมุดรายการหรือ CSV ด้วยข้อมูลที่ลบข้อมูลส่วนตัวแล้ว
7. กลับมาในวันอื่นภายใน 7 วันและเปิดหรือแก้แผนเดิม

ผู้ดำเนินการถามหลังแต่ละงานว่า “คุณคาดว่าปุ่มนี้จะทำอะไร” และ “ตัวเลขใดที่คุณจะใช้ตัดสินใจ” จดคำตอบตามจริง หลีกเลี่ยงการสอนวิธีใช้ก่อนเห็นจุดติดขัด

## นิยามผล

- Activation = จำนวนผู้ที่ได้ valid result อย่างน้อยหนึ่งครั้ง ÷ จำนวนผู้ที่เริ่มทดลอง
- Comprehension = จำนวนผู้ที่อธิบายความต่างของกำไร USD/THB ได้ ÷ จำนวนผู้ที่ทำโจทย์นั้น
- Return within 7 days = จำนวนผู้ที่กลับมาใช้อีกวัน ÷ จำนวนผู้ที่ครบช่วงติดตามแล้ว
- Interest, accepted offer และ paid ต้องรายงานแยกกัน พร้อมตัวหารและจำนวนจริง

กลุ่มเล็กนี้ใช้หาปัญหาและสัญญาณซื้อ ไม่ใช้สรุปแทนตลาดทั้งหมด

## ข้อเสนอที่ใช้ทดสอบ

- Local Pro ทดลอง: saved plans, journal, CSV และ widget ในช่วงราคา 149–249 บาท/เดือน หากภายหลังมี cloud/member service ที่ให้คุณค่าต่อเนื่อง
- Branded widget pilot: ตั้งค่าแบรนด์และช่วยฝังในเว็บไซต์ ช่วงราคา 3,000–10,000 บาทตามงานติดตั้งและการปรับแต่ง

ราคาเป็นสมมติฐานสำหรับทดสอบ ให้แสดงสิ่งส่งมอบ ระยะเวลา และข้อจำกัดก่อนถามความสนใจ การรับเงินหรือการติดต่อผู้เข้าร่วมต้องทำเมื่อเจ้าของโครงการดำเนินการหรือมอบหมายอย่างชัดเจน

## เกณฑ์ตัดสินใจหลังทดลอง

เป้าตั้งต้นคือผู้ใช้กลับมาอย่างน้อย 5 คนภายใน 7 วัน และมีการจ่ายทดลอง 3 ราย หรือ widget ที่จ่ายจริง 1 โครงการ หากไม่ถึงเป้า ให้จัดอันดับจุดติดขัดและแก้สิ่งที่ทำให้ activation/comprehension ต่ำก่อนเพิ่มระบบสมาชิก

รายงานผลต้องมีจำนวนผู้เริ่ม จำนวนที่ครบช่วงติดตาม วันที่ทดลอง สัดส่วนที่คำนวณสำเร็จ สัดส่วนกลับมา และสถานะข้อเสนอทั้งสามระดับ จากนั้นเลือกแนวทางเดียวสำหรับรอบถัดไป พร้อมเหตุผลและต้นทุนโดยประมาณ
